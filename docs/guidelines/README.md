# React engineering guidelines

This directory contains a local copy of the Reacticity React coding guidelines.
The Reacticity standard is provided as development guidance for Mycel Console;
it is not an automated source dependency or a runtime requirement.

Before planning or modifying React code, read:

```text
docs/guidelines/react_coding_guidelines.md
```

The local copy is intentionally self-contained. Updates should be made as
reviewed documentation changes when the development guidance needs to change.
